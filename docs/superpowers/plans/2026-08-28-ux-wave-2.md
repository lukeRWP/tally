> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ship the five P1 per-repetition fixes from the 2026-08-28 UX review — #219 /scan coarse fork, #227 instant-commit safety, #228 matches auto-advance + bulk clear, #225 keyboard nav everywhere, #226 in-page camera.

**Architecture:** all client-side (`client/src`), no migration, no server change, no new dependency. Spec: `docs/superpowers/specs/2026-08-28-ux-wave-2-design.md` — it governs; this plan sequences it to keep each file inside one task (capture.tsx is touched by Tasks 2 and 5 — they are sequential, and Task 5 must re-anchor, not assume, line numbers).

**Tech Stack:** React 18 + TS, TanStack Query v5, sonner toasts, vitest + testing-library, Playwright harness for Task 6.

## Global Constraints

- Client gates: `npx tsc --noEmit`, `npx vitest run`, `npm run build` (NO client eslint). Hooks above every early return.
- Tailwind tokens only; match each file's existing idiom.
- Chrome by ORIENTATION (`useLayoutMode`), INPUT by POINTER (`useCoarsePointer`); camera presence is never a gate.
- Flex-chain cap pattern: wrappers around a `flex-1` scanner carry `flex flex-col flex-1 min-h-0` unconditionally; clamp tablet-only.
- Keys inert while any input/textarea focused (`isTyping` in use-keyboard-nav.ts) — never bypass it.
- Line anchors below may drift — anchor by the quoted code, not the number.
