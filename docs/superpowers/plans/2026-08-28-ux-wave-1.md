# UX Wave 1 — Restore the Loops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The four P0s from the deep UX review — scan-once-move-many returns to `/move` in both directions, "Scan in" routes correctly, capture commits optimistically behind a reconciling receipt, and Home's search survives Back. Closes #221 #222 #223 #224.

**Architecture:** The carry store grows `pinnedDest`/`lastDest` and the page routes scans by mode (gather while carrying, distribute after a landing). `usePutDown` parallelizes the no-confirm path. Capture's `commit()` becomes append-receipt-then-background. Home's four search-state pieces move to `useSearchParams` with the merge-don't-rebuild rule.

**Tech Stack:** React 18 + TS, Zustand, TanStack Query v5, vitest + the fixture harness.

Spec: `docs/superpowers/specs/2026-08-28-ux-wave-1-design.md` (locks every design choice; the issues carry the traces). Line numbers in this plan come from the review and may have drifted a few lines — anchor by the quoted code, not the number.

## Global Constraints

- Client-only except the CLAUDE.md rewrite in Task 3. **No migration, no server change, no new dependency.**
- Client gates: `npx tsc --noEmit`, `npx vitest run`, `npm run build` from `client/`. **No client ESLint.** Server suite once at ship (untouched-but-proven).
- Hooks above every early return. Tailwind v4 tokens only. `useSearchParams` writes MERGE into existing params (`new URLSearchParams(prev)`), never rebuild — the search.tsx bug class.
- **Carry-store invariants preserved:** not persisted (carrying is physical); `pickUp` replaces (not additive by accident — `addToCarry` is the deliberate additive path); partial-batch truth (`completeMove`) unchanged.
- Fine-desk `/move` picker flow behaviour-identical except where the spec names a change; phone capture's server-call SET identical under the optimistic rewrite (order may change).
- The reentrancy gate on `land()` (busyRef/decisionRef) and the pause-on-confirm scanner semantics survive every change to `put-down.tsx`.
- `master` protected; branch `feat/ux-wave-1`; PR flow, merge on green. PR body carries "Closes #221 … #224".
